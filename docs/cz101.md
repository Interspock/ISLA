# Casio CZ-101

El Casio CZ-101 es una de las piezas que mejor resume la filosofía de ISLA: restauración física, estudio de MIDI/SysEx, preservación de sonidos históricos y creación de herramientas libres alrededor de hardware de los años 80.

## Estado del instrumento

Durante la recuperación se encontraron problemas propios de décadas de almacenamiento y uso:

- suciedad interna;
- portapilas afectado por derrames;
- problemas mecánicos y contactos;
- memoria dependiente de alimentación de respaldo;
- componentes del cartucho que requerían reparación;
- jacks y potenciómetros a revisar.

La electrónica principal y MIDI continuaron funcionando, lo que permitió comenzar el trabajo digital incluso antes de completar toda la restauración física.

## Patches manuscritos

Se conservaron hojas originales con parámetros de sonidos programados décadas atrás.

Esas hojas contienen valores de la arquitectura Phase Distortion del CZ y están siendo tratadas como una forma de código fuente histórico.

Objetivo:

```text
hoja original
    ↓
transcripción
    ↓
modelo estructurado del patch
    ↓
SysEx
    ↓
CZ-101 real
```

## Librarian Web MIDI

Se desarrolló un librarian/editor web para operar el sintetizador desde GNU/Linux mediante Web MIDI.

El trabajo incluyó:

- detección MIDI;
- permisos SysEx del navegador;
- Program Change;
- envío y recepción de SysEx;
- modelado de parámetros;
- representación visual de formas de onda y bloques de síntesis;
- pruebas contra el hardware real.

El objetivo del librarian no es emular al CZ, sino ampliar su interfaz y preservar sus sonidos.

## Rol dentro de MusE

Dentro de ISLA, el CZ puede representarse mediante dos pistas complementarias:

1. una pista MIDI que envía notas y control;
2. una pista de audio que recibe la salida física del sintetizador.

Así puede secuenciarse, grabarse y procesarse junto con instrumentos virtuales libres.
